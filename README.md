# Radio Grâce-Espoir — Back-Office Administration
### L'Évangile au cœur de l'Homme, administré avec grâce.

Back-office web pour l'administration de l'application mobile Grâce-Espoir. Il permet de gérer tout le contenu qui nourrit l'app native : actualités, émissions, événements, boutique, demandes de prière et configuration du direct.

> Stack 100% mockée pour la V1 — aucune dépendance API. Prête à brancher sur ton backend.
